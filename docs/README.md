# Documentation

This directory is the durable technical source of truth for the project.

- [Architecture](architecture/overview.md): system shape, boundaries, and
  dependencies.
- [Architectural decision records](adr/README.md): accepted and superseded
  consequential technical decisions.
- [Domain](domain/domain-map.md): initial business areas and shared terminology.
- [Development](development/agent-workflow.md): contribution workflow, principles,
  tests, and completion criteria.

Update these documents in the same pull request as any change that makes them
inaccurate. Unknown business rules should be marked `TBD`, not inferred.
